# 站点风格

正式首页是 Astro 编出来的 `dist/index.html`。视觉以暖米纸、墨绿和淡黄高亮为准，和现网已经定下来的那一版对齐。

## 色板

定义在 `src/styles/tokens.css`。

| 变量 | 色值 | 用在 |
| --- | --- | --- |
| `--bg` | `#FBF8F0` | 页面底，网格纸 |
| `--ink` | `#1C1915` | 标题和正文 |
| `--dim` | `#6F675E` | 次要说明 |
| `--green` | `#3F6E5A` | 链接、当前项之外的强调 |
| `--mark` | `#F6E38B` | 顶栏当前项的淡黄条 |
| `--yellow` | `#F5C518` | 口号里「复利」的黄线，跟现网一样 |
| `--warm` | `#C96F4A` | 便签上「先沉淀着」的下划线 |
| `--line` | `#E5DCCE` | 分区线和卡片边 |

背景是 28px 的浅网格。不要做暗色主题。

## 字体

自托管 Noto Sans SC（400 / 500）和 Noto Serif SC（700 / 900），文件在 `public/fonts/`，许可见同目录 `OFL.txt`。只打包页面上出现的字。标题用宋体 900，便签正文用 700，社交链接用黑体 500，其余用黑体 400。不要再引 Google Fonts。

## 版式

内容宽最多 1120px。

- 顶栏吸顶。`产品` / `Skills` / `文章` 是锚点，不是 Tab。滚到对应分区时，当前项加上淡黄高亮。
- Hero 左文右舞台：三行口号、一句 tagline、`findme` 社交入口。右侧黄便签可悬停抽走，人物从倚靠换成踉跄，移开后恢复。没有悬停的设备改为点按。
- 三个分区纵向排列。桌面卡片两列，左图不少于卡片一半；窄屏单列，上图下文。
- 页脚只留版权和「如果想法不能被执行，就会被雪藏。」
